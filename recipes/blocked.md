# Recipe: Blocked

Use when progress is unsafe, required information is missing, a dependency is unavailable, or two attempts fail without increasing confidence.

## Do

1. Stop speculative changes.
2. State the blocker in one sentence.
3. List what was tried.
4. List evidence gathered.
5. Name the smallest decision or external change needed to continue.
6. Suggest the safest next option.

## Hard Rules

- Do not invent fallback systems to avoid the blocker.
- Do not continue broad changes while confidence is dropping.
- Keep the report short enough for the user to act on.
