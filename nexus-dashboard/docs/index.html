Nexus CLI Docs

Commands for local-first multi-agent repo coordination
Dashboard

Commands

nexus checkin <agent>

Writes an agent heartbeat so the dashboard can show online, idle, or offline presence.

nexus checkout [--all] <agent>

Marks an agent session as ended, or clears all presence records during emergency cleanup.

nexus chmod [--list] [--init]

Shows or initializes promptCHMOD permissions for agent-safe file access conventions.

nexus claim <path> <agent> "<intent>"

Locks a file or directory before edits so other agents can see ownership and intent. Also accepts --agent <agent> and --intent "<intent>". Warns when agent, intent, or model metadata is missing.

nexus clean [--stale | <path>]

Prunes locks surgically, by stale age, or by explicit target when cleanup is needed.

nexus dashboard --serve [--port <port>]

Serves the local dashboard with claims, queue state, metrics, ledger history, and report views.

nexus db <backup|list|restore|schedule>

Runs database backup and recovery helpers for repo-local protection workflows.

nexus doctor [--fix] [--json]

Checks protocol files, private-path safety, and repo health; can repair known protocol drift.

nexus drill <list|show|run|report>

Inspects or runs protocol drills and summarizes the latest drill results.

nexus help

Prints the CLI command list, examples, and usage syntax.

nexus init

Scaffolds Nexus coordination files into the current repository.

nexus ledger [--json|backfill]

Shows or backfills the completed-task ledger that powers dashboard history and charts.

nexus metrics [--json]

Summarizes commits, release activity, queue cost, and agent attribution.

nexus next <agent>

Suggests the next safe ready task for an agent from the queue.

nexus release <path> "<commit msg>"

Releases a claim, stages and commits the target, and appends a Nexus report receipt.

nexus soul [--file <path>] [--status | --remove]

Manages local soul overlays in agent files without making them part of public docs.

nexus start [--agent @handle]

Orients an entering agent with repo facts, scoped memory paths, locks, and current status.

nexus status

Shows the current Nexus blackboard state, active locks, and coordination context.
